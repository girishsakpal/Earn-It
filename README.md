# 💰 Earn-It: AI-Powered Salary Prediction System

> An end-to-end Machine Learning application that predicts salaries based on professional and career-related attributes.

**Earn-It** is an AI-powered salary prediction system built using Machine Learning and Flask. The project demonstrates the complete Data Science workflow-from data preprocessing and feature engineering to training multiple regression models, evaluating their performance, and deploying the best-performing model through an interactive web application.

---

## 🚀 Features

* 🔮 Predict salary based on professional attributes
* 📊 Interactive dashboard and data visualizations
* 🤖 Comparison of multiple Machine Learning models
* 📈 Model performance analysis and evaluation
* 💰 Real-time salary prediction
* 🧠 Feature importance analysis
* 📉 Predicted vs actual value visualization
* 🌙 Dark/Light mode support
* 📱 Responsive user interface
* 🌐 Flask-based web application

# 🤖 Machine Learning Models

The project experiments with multiple regression algorithms, including:

* Linear Regression
* K-Nearest Neighbors Regressor
* Random Forest Regressor
* Gradient Boosting Regressor
* Support Vector Regressor
* Histogram Gradient Boosting Regressor

The models are evaluated using multiple regression metrics, and the best-performing model is selected for deployment.

---

# 📏 Model Evaluation

The Machine Learning models are evaluated using:

| Metric       | Description                                                  |
| ------------ | ------------------------------------------------------------ |
| **MAE**      | Measures the average prediction error                        |
| **MSE**      | Measures the average squared prediction error                |
| **RMSE**     | Represents the standard deviation of prediction errors       |
| **R² Score** | Indicates how well the model explains the variance in salary |

# ⚙️ Installation & Setup

### 1. Clone the repository

```bash
git clone https://github.com/girishsakpal/Earn-It.git
cd Earn-It
```

### 2. Create a virtual environment

```bash
python -m venv venv
```

### 3. Activate the environment

**Windows**

```bash
venv\Scripts\activate
```

**Linux/macOS**

```bash
source venv/bin/activate
```

### 4. Install dependencies

```bash
pip install -r requirements.txt
```

### 5. Run the application

```bash
python app.py
```

Open your browser and visit:

```text
http://127.0.0.1:5000
```
